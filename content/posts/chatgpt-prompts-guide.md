## 写作类Prompt

### 1. 文章写作
```
请帮我写一篇关于[主题]的文章，
目标读者是[人群]，
字数要求[XXX]字，
风格要求[专业/轻松/学术]，
需要包含[要点1]、[要点2]、[要点3]。
```

### 2. 标题优化
```
请为以下文章生成10个吸引人的标题，
要求：包含关键词[XXX]，
风格：[疑问式/数字式/对比式]。

文章内容：[粘贴内容]
```

### 3. 内容改写
```
请改写以下内容，
要求：保持原意，但改变表达方式，
目标：降低重复率/适应不同平台/简化语言。

原文：[粘贴内容]
```

## 编程类Prompt

### 4. 代码生成
```
请用[编程语言]实现[功能描述]，
要求：
1. 代码注释完整
2. 包含错误处理
3. 符合[编码规范]
4. 附带使用示例
```

### 5. 代码解释
```
请解释以下代码的功能和工作原理，
要求：用通俗易懂的语言，分步骤说明。

代码：[粘贴代码]
```

### 6. Bug修复
```
请帮我找出以下代码中的bug并修复，
错误信息：[粘贴错误信息]

代码：[粘贴代码]
```

## 学习类Prompt

### 7. 知识总结
```
请用表格总结[主题]的核心知识点，
要求：
1. 分门别类
2. 包含定义、特点、应用场景
3. 适合初学者理解
```

### 8. 学习计划
```
请帮我制定[主题]的学习计划，
要求：
1. 学习周期：[X]周
2. 每天学习时间：[X]小时
3. 包含学习资源推荐
4. 包含实践项目
```

### 9. 概念解释
```
请用类比的方式解释[复杂概念]，
要求：
1. 用生活中的例子
2. 分层次解释（简单→复杂）
3. 包含实际应用场景
```

## 工作类Prompt

### 10. 邮件写作
```
请帮我写一封[类型]邮件，
收件人：[身份]
主题：[主题]
要点：
1. [要点1]
2. [要点2]
语气：[正式/友好/紧急]
```

### 11. 会议记录
```
请将以下会议内容整理成结构化的会议纪要，
要求：
1. 包含决议事项
2. 包含待办任务（责任人+截止日期）
3. 包含下一步计划

会议内容：[粘贴内容]
```

### 12. 数据分析
```
请分析以下数据，
要求：
1. 给出关键指标
2. 发现趋势和规律
3. 提出优化建议
4. 用表格呈现结果

数据：[粘贴数据]
```

### 13. 头脑风暴

## 翻译类Prompt

### 15. 专业翻译
```
请将以下内容翻译成[目标语言]，
要求：
1. 保持专业术语准确
2. 符合行业表达习惯
```

```
请将以下句子翻译成英语、日语、韩语，
并解释不同语言表达的细微差别。

原文：[粘贴内容]
```

```

3. 包含每日行程

```

```
要求：
1. 目标：[减脂/增肌/塑形]
2. 每周训练[X]天
3. 包含具体动作和组数
4. 包含饮食建议
```

## 常见问题 FAQ

### Q: 为什么我的Prompt效果不好？
A: 可能是Prompt不够具体。尝试加入更多约束条件，如字数、格式、风格等。

### Q: 如何让ChatGPT回答更准确？
A: 提供上下文背景，明确输出格式，要求分步骤思考。

### Q: 这些Prompt适用于其他AI吗？
A: 大部分适用于Claude、文心一言、通义千问等AI工具。
